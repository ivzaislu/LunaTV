# Extractor scripts

В каталоге `extractor/` располагаются JS-скрипты, которые запускаются из Python-утилит
(`update_playlist.py`, `scaner.py`) для извлечения ссылок на потоки. Добавлены экстракторы:

- `smotru-m3u-one-stealth.js` — универсальный Playwright/HTTP-адаптер, умеющий
  вытаскивать `.m3u8` ссылки из DOM и скриптов Смотру.
- `cinema-hls-extractor.js` — модуль для HLS-плейеров с JSON-конфигами (данные в
  `data-player-config`, `application/json` и глобальном `playerConfig`).

- скачивает HTML целевой страницы с использованием axios;
- ищет `.m3u8` ссылки через парсинг DOM (`cheerio`) и регулярные выражения;
- возвращает массив URL-адресов в формате JSON, совместимый с ожидаемым Python-кодом;
- содержит встроенный самотест (`node extractor/smotru-m3u-one-stealth.js --selftest`);
- покрыт офлайн-фикстурами в `extractor/run-fixture-tests.js`.

По умолчанию скрипт использует [Playwright](https://playwright.dev/) для рендеринга
страницы в headless Chromium — это позволяет извлекать потоки даже с сайтов,
которые подгружают ссылки динамически. При необходимости можно отключить браузер
и заставить скрипт работать только через HTTP, передав флаг `--http-only` или
установив переменную окружения `EXTRACTOR_HTTP_ONLY=1`.

### Установка зависимостей для экстракторов

```bash
npm install                  # ставит playwright-core и утилиты
npx playwright@1.55.0 install chromium
```

`playwright-core` не содержит браузеров внутри пакета, поэтому Chromium скачивается
отдельно указанной командой. Если антивирус блокирует загрузку, выполните её внутри
Docker-контейнера либо добавьте временное исключение только на каталог проекта.

## Добавление новых экстракторов

1. Создайте файл в каталоге `extractor/` и экспортируйте в stdout JSON-массив найденных ссылок.
2. Обновите `config/site_controller.json`, чтобы сопоставить домену нужный скрипт.
3. При необходимости добавьте дополнительный самотест и не забудьте указать тайм-аут.
4. Добавьте HTML-фикстуры в каталог `extractor/fixtures/` и включите их в `run-fixture-tests.js`,
   чтобы гарантировать регрессионные тесты без доступа к целевым сайтам. В пример можно
   посмотреть `cinema-hls-player.html` (конфигурация в JSON и inline-скриптах).

Пример фрагмента `config/site_controller.json` для нового скрипта:

```json
{
  "cinema.example": {
    "script": "extractor/cinema-hls-extractor.js",
    "timeout": 20000
  }
}
```
